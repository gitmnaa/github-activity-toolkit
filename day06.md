# Day 6 — Activity Goal Analyzer

## Objective
Build a JavaScript tool to measure progress toward an activity goal.

## Features
- Calculate remaining activities.
- Calculate progress percentage.
- Estimate the daily target required.
- Detect whether the goal is completed.

## Concepts Practiced
- JavaScript objects
- Functions and parameters
- Arithmetic operations
- Conditional expressions
- Console output

## Result
The activity goal analyzer is ready for testing.

## Next Step
Improve the analyzer with user input and progress history.
